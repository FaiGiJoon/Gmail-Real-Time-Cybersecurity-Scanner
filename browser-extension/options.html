Privacy

  • The email is read from your open Gmail tab and checked inside this extension. It is not uploaded anywhere.
  • Sender and link domain names go to rdap.org to look up how old the domain is.
  • Link URLs go to Google Safe Browsing only if you set a key above.
  • Nothing else is stored except these settings.
